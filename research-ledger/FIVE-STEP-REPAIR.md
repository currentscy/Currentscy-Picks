# Five-step repair and verification — 2026-11-20

1. **NBA website** — the NBA 5 Game Parlay now stays visible even when there are fewer than three eligible picks; it shows honest empty/partial states. The browser and scheduled forecast collector use the same `nba-shared-model.js` formula. The collector now looks ahead two days, allowing pregame capture earlier than tip-off.
2. **Other sports** — `scripts/multisport-baseline.py` generates **separately labeled research-only** pregame home-win baselines from at least eight prior completed games per team, with a 20-game lookback. It does not claim to be the website's tactical simulator. It does not generate unsupported UFC/tennis picks. Each eligible forecast is timestamped before the event and associated with the event's ID.
3. **Game/fight archiving** — `scripts/unified-event-ledger.py` reuses Stage 1's 13-league scoreboard snapshot instead of making redundant calls, adds MLB/MMA/ATP/WTA checks, splits competition-level UFC fights and tennis matches when the feed exposes them, and retains observed event history. Final outcomes are linked only to existing forecasts.
4. **One research pipeline** — the six-hour workflow runs Stage 1–5, legacy multisport and football research, the all-sport archive, baseline capture, accuracy reports, and cross-source consistency diagnostics. The 15-minute NBA feedback workflow remains faster for pregame capture. Both use a common concurrency lock to avoid overlapping repository writes.
5. **Verification and tests** — both workflows now syntax-check source code; automated tests cover NBA model and outcome extraction, pregame gating, historical persistence, UFC fight splitting, and evaluation. Each run attempts to write `research-ledger/workflow-verification.json` with its actual GitHub Actions run ID, status, number of saved events, forecasts, outcomes, and whether at least one prediction has been matched to a final result. The file explicitly reports **not validated** until real evidence exists.

## How to verify
- Check the [GitHub Actions runs](https://github.com/currentscy/Currentscy-Picks/actions) for successful executions of both workflows.
- Inspect `research-ledger/workflow-verification.json`: require `jobStatusAtCheckpoint=success`, nonzero `savedPregameForecasts`, nonzero `matchedFinalOutcomes`, and `endToEndValidated=true`.
- Inspect `research-ledger/stage3/pregame-predictions.json` and `research-ledger/stage3/verified-outcomes.json` for the same `predictionId`. Check `predictedAt` strictly precedes the event's `scheduledStart` and `verifiedAt` follows it.
- Inspect `research-ledger/validation-dashboard.json` for sport-by-sport counts, and `research-ledger/unified-coverage.json` for missing sources.

**Current scope and limits:** No GitHub Actions run has been independently confirmed through the available connector. A committed workflow is not proof that it executed. No model accuracy improvement has been demonstrated. The non-NBA research baseline is not the live website simulation engine. ESPN-only final-score confirmation is not independent multi-provider verification. Unofficial MMA/tennis feeds may be unavailable or incomplete, so collecting every fight/match cannot be guaranteed. Automatic model retraining/deployment remains disabled.
